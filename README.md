# Web personal de Agustín

Sitio estático preparado para publicarse gratis con GitHub Pages.

## Antes de publicar

- Reemplazar `tuemail@ejemplo.com` y los enlaces de redes en `index.html`.
- Editar los proyectos en `script.js`.
- Sustituir los SVG de `assets/` por imágenes reales cuando estén disponibles.

## Publicación

En GitHub: `Settings` → `Pages` → `Deploy from a branch` → rama `main` → carpeta `/root`.
